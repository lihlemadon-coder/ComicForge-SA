# ComicForge SA — Solo Roadmap (Historic Fantasy)

Assumption: ~10–15 hours per week, solo dev.

## Week 1 — Foundation + Story Engine
- Day 1: Repo setup, `index.html`, CSS shell (sidebar + main)
- Day 2: Storage layer: localStorage save/load, Export/Import JSON
- Day 3: Story From Scratch form → title, logline, genre, theme, 3-act structure
- Day 4: Continue Storyline: load story bible, last episode, character states
- Day 5: Scene breaker: Cold Open / Act 1 / Act 2 / Climax / Ending / Cliffhanger
- Day 6: Continuity tracker: character power/death state validation
- Day 7: Dashboard v1 + deploy to GitHub Pages

## Week 2 — Character Bible + Dogs
- Day 8: Character Creator (all fields, incl. SA background and languages)
- Day 9: Character list; link characters to series
- Day 10: Relationship Map (text matrix: ally/enemy/family)
- Day 11: Auto-update character states after each chapter
- Day 12: Random SA side-character generator (Zulu names, rural KZN)
- Day 13: Continuity validation warnings
- Day 14: Polish + offline test

## Month 1 — Comic Builder
- Week 5: Page > Panel editor; panel visual prompt + dialogue + narration + SFX
- Week 6: Speech/thought/narration bubble CSS placeholders
- Week 7: Read Mode fullscreen reader
- Week 8: Export comic (images + HTML eBook + cover + TOC)

## Month 2 — Anime Adaptation (Motion Comic)
- Week 9: Comic page → motion-comic shot list (shot type, camera, movement, voice line, sound cue, duration)
- Week 10: 5–7 minute timer (300–420 seconds); cliffhanger marker
- Week 11: Storyboard view: Panel ↔ Motion-Comic Shot side-by-side
- Week 12: Animatic Checklist: animate vs. pan/zoom only; export Script PDF + Shot List + Voice Script

## Month 3 — Polish + Release v1
- Week 13: Progress tracker wizard
- Week 14: UX polish, mobile layout, keyboard shortcuts, autosave indicators
- Week 15: Import/Export robustness; sample historic-fantasy project included
- Week 16: Final testing offline; publish; write README

## Success Metric
One Zulu historic-fantasy one-liner → finished comic → 5–7 minute motion-comic blueprint, all offline, all free, one person.
